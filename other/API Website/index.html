Introduction

Welcome to the Moon Engine API documentation!

Moon Engine is a Friday Night Funkin’ framework built from scratch on HaxeFlixel, designed to give modders full control and creative freedom over playable characters and such.
This guide will walk you through the engine’s core features and help you start building your own mods.

WARNING: Both this page and the framework is still heavily work in progress!
So expect: Unfinished features, unimplemented events, unfinished menus, buggy bits, crashes, and more.

If you're a fellow betatester, welcome! Have fun reading. :D

Making a Stage

You probably have already implemented your songs and characters, but want some new stages.
So this section is to guide you on making your very first stage!

As a reference, here's the JSON file used for the game's week 1 stage: 

{
  "camSettings": {
    "zoom": 0.9,
    "startX": 751.5,
    "startY": 300
  },
  "objects": [
	{
      "name": "stageback",
      "position": [-600, -200],
      "scroll": [0.9, 0.9],
      "angle": 0
    },
	{
      "name": "stagefront",
      "position": [-650, 600],
      "scroll": [1, 1],
      "angle": 0
    },
	{
      "name": "stagecurtains",
      "position": [-500, -300],
      "scroll": [1.3, 1.3],
      "angle": 0
    }
  ],
  "characters": [
    {
	  "type": "opponent",
      "position": [64, 396],
      "objectBehind": "stagefront"
    },
    {
	  "type": "player",
      "position": [916, 396],
      "objectBehind": "stagefront"
    },
    {
	  "type": "spectator",
      "position": [296, 374],
      "objectBehind": "stagefront"
    }
  ]
}
